### **Название задачи:** Интеграция кол-центров с актуальными ставками по депозитам

### **Автор:** Егор

### **Дата:** 13.09.2025

### **Функциональные требования**

| **№** | **Действующие лица или системы**                                   | **Use Case**                       | **Описание**                                                                                                                                                                        |
| :---- | :----------------------------------------------------------------- | :--------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| UC-9  | Менеджер кол-центра банка, Сервис депозитов                        | Консультация по актуальным ставкам | Менеджер кол-центра банка запрашивает через свой интерфейс актуальные ставки по депозитам для консультации клиентов. Данные получаются в реальном времени из API Сервиса депозитов. |
| UC-10 | Администратор банка, Сервис выгрузки ставок, Партнерский кол-центр | Выгрузка файла ставок для партнера | При обновлении ставок в системе автоматически генерируется файл (JSON/CSV) и выгружается по SFTP на сервер партнерского кол-центра.                                                 |
| UC-11 | Сотрудник партнерского кол-центра                                  | Консультация по ставкам из файла   | Сотрудник партнерского кол-центра использует данные из полученного файла для консультации клиентов по актуальным ставкам.                                                           |

### **Нефункциональные требования**

| **№**  | **Требование**                                                                                                                  |
| :----- | :------------------------------------------------------------------------------------------------------------------------------ |
| NFR-9  | Данные о ставках должны быть доступны кол-центру банка в реальном времени с задержкой не более 1 секунды.                       |
| NFR-10 | Выгрузка файла для партнерского кол-центра должна происходить автоматически при каждом изменении ставок.                        |
| NFR-11 | Обмен файлами с партнерским кол-центром должен быть безопасным (использовать SFTP с шифрованием).                               |
| NFR-12 | Система должна поддерживать возможность подключения дополнительных партнерских кол-центров в будущем без изменения архитектуры. |

### **Решение**

Для предоставления доступа к актуальным ставкам обоим кол-центрам расширяем ранее предложенную архитектуру двумя способами:

- Для внутреннего кол-центра банка: Предоставляем доступ к существующему API Сервиса депозитов через API Gateway.
- Для партнерского кол-центра: Вводим новый сервис для асинхронной выгрузки файлов по SFTP.

### **Альтернативы**

1. Прямой доступ кол-центра банка к АБС:

   1. Нарушает NFR-5, создает нагрузку на АБС

2. Кол-центр банка использует файловый обмен так же, как партнер:

   1. Не удовлетворяет требованию реального времени (NFR-9)

3. Партнерский кол-центр использует API:

   1. По условию, нет возможности для API-вызовов

### **Список крупных задач для каждой системы**

1.  **Сервис депозитов:**

    - Модификация для публикации события `RateUpdated` в Kafka при каждом обновлении кэша ставок.
    - Создание и настройка топика Kafka `rates-update`.

2.  **Сервис выгрузки ставок (новый):**

    - Разработка микросервиса, подписанного на топик `rates-update`.
    - Реализация логики генерации файлов в форматах JSON/CSV.
    - Реализация SFTP-клиента для загрузки файлов на внешние серверы.
    - Разработка механизма конфигурирования подключений к партнерам (адреса, учетные данные).

3.  **API Gateway:**

    - Настройка эндпоинта и правил доступа для запросов от системы кол-центра банка к API Сервиса депозитов.

4.  **Инфраструктура и безопаность:**

    - Развертывание и настройка SFTP-сервера (или использование облачного решения).
    - Настройка безопасного хранения учетных данных для SFTP (например, в HashiCorp Vault).
    - Настройка мониторинга процесса выгрузки файлов.

5.  **Партнерский кол-центр:**
    - Координация с партнером: предоставление спецификации формата файла, настройка SFTP-доступа.
